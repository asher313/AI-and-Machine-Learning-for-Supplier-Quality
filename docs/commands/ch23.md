## 23.8 ECR, ECS, and EKS — Running Containers

```bash
# Build/push the TRAINING image after creating its ECR repository.
# Requires Docker, AWS CLI, approved credentials and configured REGION.
ACCOUNT=$(aws sts get-caller-identity --query Account --output text)
SHA=$(git rev-parse HEAD)
REGISTRY="$ACCOUNT.dkr.ecr.$REGION.amazonaws.com"
aws ecr get-login-password --region "$REGION" \
  | docker login --username AWS --password-stdin "$REGISTRY"
docker build -f docker/Dockerfile.training -t "$REGISTRY/supplier-book-training:$SHA" .
docker push "$REGISTRY/supplier-book-training:$SHA"
# Record the registry image digest for sm_train.py; a tag is mutable.
```

## 23.8 ECR, ECS, and EKS — Running Containers

```powershell
# Windows PowerShell; configure $env:AWS_REGION first.
$ACCOUNT = aws sts get-caller-identity --query Account --output text
$SHA = git rev-parse HEAD
$REGISTRY = "$ACCOUNT.dkr.ecr.$env:AWS_REGION.amazonaws.com"
aws ecr get-login-password --region $env:AWS_REGION |
  docker login --username AWS --password-stdin $REGISTRY
docker build -f docker/Dockerfile.training -t "$REGISTRY/supplier-book-training:$SHA" .
docker push "$REGISTRY/supplier-book-training:$SHA"
# Check command exit codes and record the immutable image digest.
```
