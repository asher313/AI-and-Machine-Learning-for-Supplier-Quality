# Chapter 23 — commands

## 23.8 ECR, ECS, and EKS — Running Containers

ed. **Elastic Container Registry (ECR)** stores the image. **Elastic Container Service (ECS)** runs containers with Amazon's own scheduler, and on **Fargate** there are no machines to patch. **Elastic Kubernetes Service (EKS)** runs Kubernetes, which is more capable and considerably more to operate.

```bash
# Build and push the image (macOS / Linux)
ACCOUNT=$(aws sts get-caller-identity --query Account \
  --output text)
REGISTRY="$ACCOUNT.dkr.ecr.us-east-2.amazonaws.com"
aws ecr get-login-password --region us-east-2 \
  | docker login --username AWS --password-stdin "$REGISTRY"
docker build -t "$REGISTRY/sqm-ai/ncr-classifier:$SHA" .
docker push "$REGISTRY/sqm-ai/ncr-classifier:$SHA"
```

