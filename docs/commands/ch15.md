# Chapter 15 — commands

## 15.10 Local Inference

* is the developer's tool: one command pulls a model, one call runs it, and it handles the GPU, the CPU fallback, and quantization for you. **Quantization** stores model weights in fewer bits — four instead of sixteen — so a model that needed forty gigabytes fits in ten, at a small cost in accuracy.

```bash
# macOS / Linux
ollama pull llama3.3
```

```powershell
# Windows PowerShell (after installing Ollama for Windows)
ollama pull llama3.3
```

le holds locally too. **vLLM** is the server's tool: a high-throughput inference engine that batches concurrent requests on one or more GPUs and speaks an HTTP protocol most client libraries already understand. You start it once, on a machine with the GPUs, and every service on the network calls it.

```bash
# On the GPU host (snapshot: vLLM CLI as of September 2026)
vllm serve meta-llama/Llama-3.3-70B-Instruct \
    --tensor-parallel-size 4 --max-model-len 8192
```
