# Chapter 2 — commands

## macOS

1. **Open Terminal.** Press Cmd-Space, type `Terminal`, press Return. 2. **Install Git and the compiler tools.** Type the line below and press Return. A dialog appears; click **Install**, then **Agree**. It takes a few minutes.

```bash
xcode-select --install
```

3. **Install `uv`.** The official installer is a shell script. Download it to a file first and read it before you run it; piping an unread script from the internet into your shell is a habit this book will not teach you.

```bash
curl -LsSf https://astral.sh/uv/install.sh -o uv-install.sh
less uv-install.sh        # press q to leave
sh uv-install.sh
```

Then **quit Terminal and reopen it**, so the new `uv` location is on your PATH. (If you use Homebrew, `brew install uv` does the same thing.) 4. **Install Python 3.12.** `uv` downloads a self-contained build; it does not touch the Python that ships with macOS.

```bash
uv python install 3.12
```

## Windows

1. **Open PowerShell.** Press the Windows key, type `PowerShell`, press Enter. Do not run it as Administrator; nothing here needs it. 2. **Install Git.**

```powershell
winget install --id Git.Git -e --source winget
```

Accept the license prompt. When it finishes, **close PowerShell and reopen it.** 3. **Install `uv`.**

```powershell
winget install --id astral-sh.uv -e
```

Close and reopen PowerShell again. (The alternative is the official script: `irm https://astral.sh/uv/install.ps1 | iex`. As on macOS, save it to a file and read it first if you take that route.) 4. **Install Python 3.12.**

```powershell
uv python install 3.12
```

5. **Install Visual Studio Code.**

```powershell
winget install --id Microsoft.VisualStudioCode -e
```

If you prefer the graphical installer from `code.visualstudio.com`, tick **Add to PATH** on the options page; `winget` does that for you. Reopen PowerShell, then:

```powershell
code --install-extension ms-python.python
code --install-extension charliermarsh.ruff
```
