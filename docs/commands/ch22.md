## 22.4 Runners and GPUs

Before pushing a change to the pipeline file, lint it against the server rather than discovering the mistake in a run. The command differs by shell.

```bash
# macOS / Linux
curl -sS --header "PRIVATE-TOKEN: $GL_TOKEN" \
  --form "content=<.gitlab-ci.yml" \
  "https://gitlab.northlake.internal/api/v4/projects/\
$PROJECT_ID/ci/lint"
```

```powershell
# Windows PowerShell
$body = @{ content = Get-Content .gitlab-ci.yml -Raw }
Invoke-RestMethod -Method Post -Body $body `
  -Headers @{ "PRIVATE-TOKEN" = $env:GL_TOKEN } `
  -Uri ("https://gitlab.northlake.internal/api/v4" +
        "/projects/$env:PROJECT_ID/ci/lint")
```
