## 22.4 Runners and GPUs

```bash
# macOS / Linux; GL_TOKEN and PROJECT_ID belong to your GitLab instance.
curl --fail-with-body --silent --show-error \
  --header "PRIVATE-TOKEN: $GL_TOKEN" \
  --form "content=<.gitlab-ci.yml" \
  "https://gitlab.northlake.internal/api/v4/projects/$PROJECT_ID/ci/lint" \
  --output ci-lint.json
python -c 'import json; r=json.load(open("ci-lint.json")); print(r.get("errors", [])); raise SystemExit(0 if r.get("valid") else 1)'
```

## 22.4 Runners and GPUs

```powershell
# Windows PowerShell
$body = @{ content = Get-Content .gitlab-ci.yml -Raw }
$result = Invoke-RestMethod -Method Post -Body $body `
  -Headers @{ "PRIVATE-TOKEN" = $env:GL_TOKEN } `
  -Uri ("https://gitlab.northlake.internal/api/v4" +
        "/projects/$env:PROJECT_ID/ci/lint")
if (-not $result.valid) { throw ($result.errors -join "`n") }
```
